# Grand-Global-Travels- ✈️

A premium travel consultancy and management website built with a sophisticated Navy and Gold theme. This platform offers a seamless user experience for booking flights, visas, and luxury travel packages.

## 🌟 Features
- **Multi-Step Booking Flow:** A custom, responsive booking form that captures trip details, traveller counts, and budgets.
- **Firebase Integration:** Uses Firebase Authentication for user sign-ups and Firestore for storing booking requests and contact inquiries.
- **WhatsApp Integration:** Automatically generates a pre-filled WhatsApp message for direct communication with travel agents.
- **Responsive Design:** Optimized for mobile and desktop using Bootstrap 5 and custom CSS.
- **Real-time Notifications:** Custom toast notifications for form submissions and authentication events.

## 🛠️ Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
- **Backend/Database:** Firebase Firestore
- **Authentication:** Firebase Auth (Email/Password & Google)
- **Animations:** WOW.js & Animate.css

## 🚀 Getting Started
1. Clone the repository.
2. Update the Firebase configuration in `js/firebase-app.js` with your own credentials.
3. Open `index.html` in your browser or host it via Firebase Hosting.
